# UX audit — 2026-10-07

Цель: ощущение отзывчивого рабочего пространства, без персонажа. Референс —
[Coucou](https://github.com/Louis-CFM/coucou): видимое состояние агента,
обратная связь рядом с действием, короткий путь от уведомления к ответу.
Это аудит конкретных сценариев, а не утверждение об отсутствии других проблем.

## Исправления

| Проблема | Изменение | Проверка |
| --- | --- | --- |
| До прихода JS — пустая страница | Начальное состояние `Starting your workspace…`, заменяемое React | E2E с задержкой JS |
| Пунктирный квадрат трудно отличить от декора | Единый вращающийся индикатор для загрузки и действий | E2E computed styles, reduced motion |
| Скелетоны — практически невидимые линии высотой 1 px | Заполненные строки высотой 8 px и более спокойная пульсация | E2E с задержкой списка сессий |
| В квадратной кнопке во время ожидания теснились две иконки | Спиннер замещает иконку без изменения размера кнопки | E2E геометрии |
| Пустой экран лишь отправлял пользователя искать форму | Кнопка `Choose a project` раскрывает форму и фокусирует поле | Unit + desktop/mobile E2E |
| Ошибка списка сессий не показывалась на пустом экране чата | Ошибка и Retry непосредственно на этом экране | Unit |
| Горячая клавиша новой сессии не раскрывала скрытую панель/форму | Общая навигация для кнопки и клавиатуры | Unit + E2E |
| Переименование позволяло пересекающиеся запросы; пустое имя не показывало сохранение | Видимый спиннер, доступный статус, защита от повторного редактирования с сохранением фокуса | Unit с незавершённым запросом |
| Автодополнение перехватывало Enter и Escape у IME | До обработки команд проверяется композиция ввода; то же для имени | Unit |
| Копирование не показывало ожидание Clipboard API | `Copying…`, защита от повторного запроса, затем `Copied` | Unit с задержкой |
| Legacy-копирование сбрасывало фокус | Возврат фокуса без прокрутки, включая ошибку копирования | Unit |
| Копирование пути терминала не работало по HTTP | Общая кнопка копирования с fallback и подтверждением на месте | Unit |
| Копирование выделения терминала молча игнорировалось по HTTP | Тот же fallback, что в чате | Unit |
| Устаревшая подсказка могла заменить уже изменённый ввод | До получения актуальных вариантов выбор заблокирован | Unit с задержкой |
| Undo исчезал во время взаимодействия | Пауза таймера при наведении/фокусе, затем оставшееся время | Unit + E2E архивации |

## Уже присутствует

- Черновики по сессиям, очередь отправки, восстановление текста после ошибки.
- Состояния загрузки/ошибки истории, моделей, изменений, файлов, папок и терминалов.
- Работающий агент с таймером; отдельное состояние ожидания пользователя.
- Пауза live-обновлений, отсчёт до переподключения, ручная попытка.
- Непрочитанные ответы, переход к последнему сообщению, статус вкладки.
- Горячие клавиши, быстрый переключатель, focus mode, мобильные панели.
- Уменьшенное движение, опциональный звук, подтверждение удаления worktree.

## Следующий проход

Эти пункты не входят в исправления выше и пока не считаются закрытыми.

1. **Начальная загрузка:** основной JS bundle около 1.16 MB до gzip.
   Разделить терминал и диагностику на ленивые модули; измерить время до
   доступного чата на медленной сети. Индикатор объясняет ожидание, но не
   сокращает его.
2. **Мобильная эргономика:** маленькие служебные кнопки, подсказки только через
   `title`, экранная клавиатура и реальные touch-сценарии требуют отдельного
   прохода на устройстве; эмуляция viewport не заменяет его.
3. **Контекст работы:** общий `working` можно дополнять текущим действием
   агента, если оно достоверно известно из событий. Не подменять реальные
   состояния случайными фразами или вымышленным процентом выполнения.

Персонаж, новые звуки и декоративные постоянные анимации не добавляются.

## Проверка

- Vitest: 1355 тестов, 105 файлов; покрытие строк 97,26%, ветвей 93,30%.
  Команда: `npm run test:cov -- --maxWorkers=2 --testTimeout=15000`.
- Выбранная браузерная регрессия: 79 сценариев прошли (74 в основном
  прогоне, 5 при повторе), 13 пропущены по типу устройства. Включены
  loading-feedback, archive, chat-ux, polish, header-fit, shortcuts,
  motion, rename и requests.
- Тест очереди больше не опирается на искусственные 400 мс: сеть
  разблокируется после проверки трёх ожидающих сообщений.
- Перед повтором обновлены `bin/fakes/claude` и `bin/fakes/codex`.
- `make build`, `make lint`, `git diff --check` прошли; после последних
  TS-изменений повторены сборка и web lint.
- Stryker для `clipboard.ts` и `notices.ts`: 73,30% при пороге 70%
  (139 killed, 1 timeout, 44 survived, 7 no coverage). Для этого прогона
  использовалась временная конфигурация Vitest с тремя профильными файлами
  тестов; общий предварительный прогон ранее превысил лимит пяти минут.
- Полный `make check` для Go и всего набора мутаций не запускался.

Изменения сохранены в рабочей копии, бинарник собран. Запущенный экземпляр
приложения автоматически не перезапускается.
